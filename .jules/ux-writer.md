## 2026-01-24 - Empty State & Terminology Improvement

**Copy Type:** Empty State & Navigation

**Original:**
- Breadcrumb: "Tasks"
- Empty State: "Nenhum áudio enviado" / "Envie seu primeiro arquivo para gerar highlights automaticamente."
- Button: "Novo Upload"
- Tooltip: "Excluir task"

**Changed To:**
- Breadcrumb: "Meus Projetos"
- Empty State: "Comece seu primeiro projeto" / "Faça upload de um áudio ou vídeo para gerar highlights, transcrições e clipes automaticamente."
- Button: "Novo Projeto"
- Tooltip: "Excluir projeto"

**Learning:**
- Shifting from technical terms ("Tasks", "Upload") to value-based terms ("Projects") makes the app feel more professional and less like a file utility.
- Empty states should be invitations to create value ("Start your first project"), not descriptions of emptiness ("No audio sent").
- "Projects" implies a workspace with multiple outputs (highlights, clips, transcripts), whereas "Tasks" implies a single background job.

**Rule:**
- Use "Projeto" (Project) instead of "Task" in user-facing copy.
- Use "Novo Projeto" instead of "Novo Upload" for the primary creation action.
- Empty states must be actionable and encouraging.
